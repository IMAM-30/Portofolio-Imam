# Portofolio Imam Hudzaifah

Website portofolio statis berbasis Next.js untuk menampilkan profil, pengalaman, proyek, dan kemampuan Imam Hudzaifah.

## Menjalankan secara lokal

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`.

## Pemeriksaan

```bash
npm test
npm run lint
npm run build
```

## Deploy ke Vercel

1. Push folder ini ke repository GitHub.
2. Masuk ke Vercel dan pilih **Add New → Project**.
3. Impor repository tersebut.
4. Pastikan Framework Preset terdeteksi sebagai **Next.js**.
5. Biarkan pengaturan build bawaan, lalu pilih **Deploy**.

Website ini tidak membutuhkan database, environment variable, atau backend eksternal.
